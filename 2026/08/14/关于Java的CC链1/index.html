关于Java的CC链1

Apache Commons是Apache软件基金会的项目，曾经隶属于Jakarta项目。Commons的目的是提供可重用的、解决各种实际的通用问题且开源的Java代码。Commons由三部分组成：Proper（是一些已发布的项目）、Sandbox（是一些正在开发的项目）和Dormant（是一些刚启动或者已经停止维护的项目）。

Commons Collections包为Java标准的Collections API提供了相当好的补充。在此基础上对其常用的数据结构操作进行了很好的封装、抽象和补充。让我们在开发应用程序的过程中，既保证了性能，同时也能大大简化代码。

改完之后在这个语句依旧是 null

2.map.put("key", "aaa");改为map.put("value", "aaa");

那我们依旧看到 Target.java 这里，我们尝试将 map 输入的数据中 key 改为value。

这样就能行了，那为什么改了这两个地方就能满足条件继续往下走呢？原因有以下三点

  • “value” 是 Target 注解中存在的属性名，使得 memberType != null 成立，从而进入 setValue() 触发漏洞链
  • 当 memberType 为 String[].class 时，memberType.isInstance("aaa") 返回 false
  • 所以会进入 setValue() 分支触发漏洞

现在我们就能继续往下走了，由于后面都是满足条件的，就不做过多解释。
